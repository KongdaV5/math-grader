## 交付内容

1. 普通老师“开始批改”页面新增 Submission Workspace：展示 Assignment → Student → Submission → Pages，并可查看学生原始作业照片。Capture finish 后老师可以直接“查看并开始批改”。
2. 老师可为本次 Assignment 选用已有题册，或对当前多页试卷调用 Qwen3-VL 4B 整页分析。Draft Exam Template 展示 AI 题目结构、答案区域与标准答案候选，老师可修改后一次确认。
3. 老师确认后临时模板只绑定当前 Assignment。Assignment 内后续学生复用它，不再对整页试卷运行分析。
4. 普通 Assignment 批改流程使用现有 PP-OCR、Formula、Qwen 路由识别答案区域；确定性规则判分，低置信度/答案键缺失等情形进入人工复核。
5. 每个题目保存 QuestionResult，提交结果保存总分与满分；人工复核更新结果，所有待复核项目处理后完成 Submission。
6. Human Review 页面展示题目所在页、题号、学生作业图、识别答案与标准答案，并支持老师判正确/错误。发现重复题号缺少页码上下文后，当前标题显示为“第 N 页 · 第 M 题”。

## 真实模型和 E2E 证据

### 隔离服务真实模型 E2E

- 使用本机真实 Qwen3-VL 4B MLX 和 PP-OCRv6 Small；数据库与图片都在隔离临时目录。
- Student A 四页试卷只做一次整页分析，Qwen 提出 8 道题。教师确认后，对该生 8 个答案区域执行 PP-OCR Small 和确定性规则，Submission 完成 **8/8**。
- Student B 四页作业复用同一 Assignment 临时模板，没有第二次整页 Qwen 分析；识别 8 个答案区域后完成 **7/8**。
- 这些是构造的合成试卷，不含真实学生作业。结果证明模型、服务、模板复用和打分链路接通，不构成准确率 Benchmark。

### 普通桌面老师 UI 浏览器 E2E

- 通过 React UI 创建临时班级、两位学生和 Assignment，上传 4 页合成作业；Submission Workspace 直接显示四张原图和页数。
- 在普通老师页点击“自动分析本次试卷”，本机 Qwen 整页分析四页合成试卷并生成 32 个题目/答案区域/答案候选。通过 UI 一次确认 Assignment 临时模板。
- Student A 进入普通识别判分。合成答案框刻意没有真实学生答案，因此低置信度结果进入 Review；人工复核 UI 实际确认一道题，待复核数量从 32 减至 31。
- Student B 上传四页后看见同一份已确认结构，并直接开始识别/判分；没有再次出现整页分析步骤。Student B 的合成答案也留在待复核队列。
- 此 UI E2E 确认了老师操作、原图显示、模板确认/复用、Review 交互。Final score 的完整结果以隔离服务真实模型 Student A / B E2E 和自动化用例为验收证据。
