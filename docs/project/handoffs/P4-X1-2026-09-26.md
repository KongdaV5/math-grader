## 图片与模板

- P2 Capture 上传在安全落盘后立即响应；后台 Image Job 复用 SQLite jobs/worker，运行 ImagePipeline 并将 processed image、状态、开始/结束时间、页面/透视标记、模糊/曝光评分、变换、warning/error 写回 SubmissionPage。状态为 PENDING / PROCESSING / READY / WARNING / FAILED，质量异常可作为 WARNING 继续。
- Template Editor 可导入并持久保存参考页、编辑/删除题目及受控答案类型、管理一题多个区域。区域以 0..1 坐标保存；画布可拖框、选中、重画、删除，另有精确数值输入。坐标变换经过屏幕、图像和归一化三层；不将 CSS 像素入库。
- 模板编辑提升版本；SubmissionPage 人工绑定保存模板与 processed image 快照。旧 RecognitionRun 记录模板版本和模型 revision。候选匹配采用 ORB 特征与 RANSAC，只提供分数，低分返回 `NO_CONFIDENT_TEMPLATE_MATCH`，不会自动绑定。
- Crop Pipeline 从绑定快照裁图，保护边界和非空，UUID 文件存 Application Support `images/crops`，保存题目、region_index、归一化/pixel bbox、大小及版本。Recognition Lab 显示 processed page、overlay 和 crop。
