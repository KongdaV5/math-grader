## 目标与实现边界

将 Math Grader 的 Python 服务与生产依赖随 `.app` 交付，用户通过 Finder 打开应用即可启动服务。模型权重仍由用户在模型中心安装到 Application Support，不随 app 打包，也不在应用启动时载入。

Release 只使用 `.app` Resources 中显式指定的 CPython executable；不回退到 PATH 中的系统 Python 或用户虚拟环境。Tauri 管理服务单实例、子进程工作目录、隔离的 Python 环境变量、服务日志和应用退出时的进程回收。

本轮没有处理最终准确率 Benchmark、Confidence 策略、真实学生作业评估、Developer ID 发布签名/公证、Windows/Intel 构建或 8B 模型。

## Runtime 和依赖

- App version：`0.1.0`
- Runtime：relocatable CPython **3.12.14 arm64**
- Python dependencies：由仓库 `uv.lock` 锁定。实际 bundle 版本包括 Pillow **11.3.0**、NumPy **2.3.5**、OpenCV **4.10.0**、ONNX Runtime **1.30.0**、Hugging Face Hub **1.33.0**、PaddlePaddle **3.3.1**、PaddleOCR **3.7.0**、MLX **0.32.2**、mlx-vlm **0.7.3**。
- Tauri Runtime manifest 独立于 app version，记录 Python、架构、依赖版本、build date、lockfile hash 和源码 Git SHA。
- 支持目标：Apple Silicon `arm64`、macOS **15.0+**。最低版本来自本轮 MLX wheel 的系统要求。
- 签名：本地 **ad-hoc** sign 与 `codesign --verify --deep --strict` 成功；**未公证**，`hardenedRuntime=false`。本地验证不代表公开分发 Gatekeeper 验收完成。
- 最终 `.app` 大小约 **1.3 GB**。Bundle verifier 检查本机架构、Python/native runtime 资源、Capture 页面、P5 frontend assets 与 runtime manifest，并拒绝打包 `.safetensors` 权重。

## P5 installed service 纵向 E2E

使用最终 bundle service、isolated SQLite/data profile、本机已有模型和合成图：

1. 创建合成班级、两名学生与 Assignment，启动 Capture Session。Capture listener 使用发现的 LAN 地址；Session token 不打印。
2. Student A 上传三页，删除中间页并重排，再补拍；finish 后进入 Student B。Student B 上传三页并 finish。核对最终页数、页归属与原图读取。
3. Qwen 4B 对 Student A 的 Submission 做一次整页试卷分析；老师编辑/确认临时模板。
4. Student A 对模板答案区域运行 OCR，使用确定性规则判分；缺答案键项进入 Human Review，审核完成后保存 QuestionResult 和 Submission 分数，最终 **3/3**。
5. Student B 复用同一个 Assignment 临时模板，没有重复整页分析；完成识别、Review 与结果保存，最终 **3/3**。
6. 清理临时 Capture Session；所有学生、图片与成绩为合成测试数据。
