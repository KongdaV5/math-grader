## 架构

```text
Tauri 2 / React / TypeScript
↓ HTTP（loopback）
Python 标准库 Local Service
↓
SQLite schema migrations
↓
Class / Student / Assignment / Submission / SubmissionPage
↓
集中 Submission 状态机
↓
SQLite FIFO jobs + 后台 worker
↓
Recognition Gateway + Provider Registry
↓
可配置 Mock Provider → RecognitionResult 入库 → Desktop 显示
```

- Database schema 版本由 SQLite `user_version` 和 SQL migration 文件管理。
- Desktop 不直接访问 SQLite；状态迁移由 `local_service/state_machine.py` 唯一管理。
- Finish 在事务中校验至少有一页、记录 `finished_capture_at` 并将任务原子入队；worker 顺序处理并在失败时记录 job/submission error 后继续。
- 本地 HTTP 服务默认只监听 `127.0.0.1`；React 使用 JSON API，可添加占位页或上传本地测试图片。
- Provider routes/model name/confidence/text 由 `local_service/config/recognition.json` 提供；Provider Registry 支持注册后续适配器。
- Tauri 在窗口启动时启动 Python 服务，服务与页面数据存放到本地应用数据目录；bundle resources 包含服务代码、迁移和配置。
